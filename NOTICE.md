## What is (and is not) bundled

The bundled data contains only factual game information: entry names, numbers,
categories, stats, drops, cooking effects and common region names.

On purpose, it does **not** include Nintendo's in-game description text, images,
icons, map tiles or any game files. The package makes no network requests.
